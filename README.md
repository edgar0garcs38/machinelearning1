# Machine Learning I: Python for Data Science Foundations

Coursework notebooks from my Machine Learning I course, covering the Python foundations used in data science. Each notebook has an exported PDF next to it for quick reading.

## Contents
| Notebook | Topic |
|---|---|
| `introduccion` | Introduction to Python and Jupyter |
| `datatypes` | Data types and data structures |
| `PythonControl` | Control flow: conditionals, loops, functions |
| `ficheros` | Reading and writing files (TXT, CSV) |
| `NumPy` | Numerical computing with NumPy arrays |
| `Pandas` | Data manipulation and analysis with pandas |
| `examennocturno` | Exam exercises |

## Tech stack
Python · Jupyter · NumPy · pandas

## Run it
```bash
pip install jupyter numpy pandas
jupyter notebook
```
